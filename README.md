# Gabe's Workshop

Лабораторна робота №5, варіант 1. Каталог інді-ігор з відгуками, щось типу маленького Steam.

## Що вміє

- показує каталог ігор: обкладинка, назва, розробник, жанр
- ціна зі знижкою: стара ціна закреслена, нова виділена, поруч бейдж «-50%»
- рейтинг рахується з відгуків і показується кольоровим бейджем (Overwhelmingly Positive, Positive, Mixed, Negative, No Reviews)
- знижку можна швидко змінити прямо з картки (від 0 до 90%)
- фільтр по жанру, він зберігається в адресі
- додавання нової гри через модальне вікно з перевіркою полів
- сторінка гри: банер, опис, ціна, список відгуків
- можна написати відгук (рекомендую / не рекомендую, години, текст) і рейтинг одразу оновлюється без перезавантаження
- видалення відгуків і самої гри (разом з її відгуками)
- сповіщення (toast) про успіх і про помилки сервера

## З чого складається

**backend** — Express + TypeScript. Дані лежать у `data/games.json` і `data/reviews.json`. Сервер сам рахує фінальну ціну, відсоток позитивних відгуків і статус рейтингу.

**frontend** — Vue 3 + TypeScript, Pinia, Vue Router, Tailwind + DaisyUI, іконки Lucide. Код розбитий на шари: компонент → composable → сервіс → httpClient (axios).
